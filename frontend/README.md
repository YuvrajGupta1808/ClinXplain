# ClinXplain - AI Medical Scribe

ClinXplain is a professional AI-powered clinical documentation platform designed to transform patient visits into comprehensive medical notes.

## Features

- **Real-time Transcription**: Capture every detail of patient conversations with live text updates.
- **AI Insights & Differentials**: Get intelligent suggestions and potential diagnoses during the visit.
- **Automated SOAP Notes**: Generate comprehensive clinical notes automatically using Google Gemini.
- **Multilingual Support**: Professional transcription and translation support.
- **Professional Dashboard**: Manage patients and visits in a clean, blue-white professional interface.

## Run Locally

**Prerequisites:** Node.js

1.  **Install dependencies:**
    `npm install`
2.  **Set the API Key:**
    Set the `GEMINI_API_KEY` in `index.tsx` or your environment.
3.  **Run the app:**
    `npm run dev`
